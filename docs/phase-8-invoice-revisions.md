# Phase 8 Invoice Revisions

Draft lines and source snapshots are retained as invoice data and workflow history is append-only. The current UI can inspect invoice details, preview a clearly marked draft, and view review history. Issued invoice mutation, cancellation, replacement, credit notes, debit adjustments, and statutory voids are not exposed because no applicable company/legal procedure has been verified. Before those are implemented, use separate correction records and preserve the original issued document and source allocations.
